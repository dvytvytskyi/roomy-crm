# Dashboard Documentation

## Огляд

Новий dashboard створено з правильною авторизацією та всіма необхідними компонентами згідно з вимогами.

## Структура

### Компоненти

- `CheckInOutStats` - Показує кількість check-ins та check-outs
- `MaintenanceStats` - Показує кількість завдань maintenance в процесі
- `UnitStats` - Показує загальну кількість одиниць та порожніх одиниць
- `BirthdaysSection` - Показує дні народження staff, guest та owner
- `DTCMAlerts` - Показує попередження про закінчення DTCM дозволів
- `UtilitiesReminders` - Показує нагадування про оплату комунальних послуг
- `DashboardLayout` - Основний компонент layout з авторизацією

### Авторизація

Dashboard захищено через:
1. **AuthGuard** - компонент, який перевіряє автентифікацію
2. **Middleware** - Next.js middleware для захисту маршрутів
3. **API Authentication** - JWT токени для API запитів

### API Endpoints

- `GET /api/v2/dashboard/stats` - Отримання статистики dashboard
  - Вимагає JWT токен
  - Повертає всі необхідні дані для відображення

### Функціональність

#### Check-ins & Check-outs
- Кількість check-ins сьогодні
- Кількість check-outs сьогодні

#### Maintenance
- Кількість завдань maintenance в процесі

#### Unit Statistics
- Загальна кількість одиниць
- Кількість порожніх одиниць (більше 7 ночей)

#### Birthdays
- **Staff**: дні народження сьогодні та протягом 7 днів
- **Guest**: дні народження сьогодні та протягом 7 днів  
- **Owner**: дні народження сьогодні та протягом 7 днів

#### DTCM Permits Expiry
- Одиниці з дозволами, що закінчуються протягом 7 днів

#### Utilities Payment Reminder
- Нагадування про оплату комунальних послуг

### Автооновлення

Dashboard автоматично оновлюється кожні 5 хвилин.

### Українська локалізація

Всі тексти інтерфейсу відображаються українською мовою згідно з налаштуваннями користувача.

## Використання

1. Користувач має бути авторизований
2. Перехід на `/dashboard` автоматично перенаправить на `/login` якщо не авторизований
3. Dashboard завантажить всі дані з API
4. При помилках відображається повідомлення з можливістю повторного запиту
