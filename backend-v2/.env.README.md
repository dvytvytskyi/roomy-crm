# .env File Protection

## 🔒 Статус: Файл захищено від редагування

Права: `-r--r--r--` (тільки читання)

## 📝 Як відредагувати (якщо потрібно)

### 1. Розблокувати файл
```bash
chmod 644 .env
```

### 2. Відредагувати
```bash
nano .env
# або
vim .env
```

### 3. Заблокувати знову
```bash
chmod 444 .env
```

## ⚠️ ВАЖЛИВО!

- **НЕ комітьте** .env файли в git (вони вже в .gitignore)
- **НЕ діліться** API ключами з іншими
- **Завжди блокуйте** після редагування

## 🔑 Токени в файлі

- ✅ Apify API Token
- ✅ PriceLabs API Key  
- ✅ AWS S3 Credentials
- ✅ Database URL
- ✅ JWT Secret
